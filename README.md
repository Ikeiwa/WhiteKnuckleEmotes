# WhiteKnuckleEmotes
Bepinex mod for White Knuckle that add custom emotes to your player hands.

### An example emote can be found in the "ExampleHand" folder

# Manual Installation
- Install [Bepinex 5](https://github.com/BepInEx/BepInEx)
- Install [WKLib](https://github.com/monksilly/WKLib/)
- Place WhiteKnuckleEmotes.dll in "[Game Folder]/BepInEx/plugins"
